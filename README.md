# risk-management-hw1

### Висновки аналізу ризику для акцій AAPL (Apple)

| Метрика ризику | Метод обчислення | Рівень довіри | Значення |
| :--- | :--- | :---: | :---: |
| VaR (Value at Risk) | Історичний (Historical) | 95% | **-2.41%** |
| VaR (Value at Risk) | Параметричний (Parametric)| 95% | **-2.55%** |
| VaR (Value at Risk) | Історичний (Historical) | 99% | **-4.26%** |
| ES (Expected Shortfall)| Історичний (Historical) | 95% | **-3.71%** |

#### Коротка аналітика результатів:
1. **Value at Risk (VaR 95%):** З імовірністю 95% максимальний денний збиток за акціями AAPL за звичайних ринкових умов не перевищить 2.41% (історичний метод) або 2.55% (параметричний). Близькість цих показників свідчить про те, що розподіл дохідностей активу на цьому рівні є відносно близьким до нормального.
2. **Хвостовий ризик (VaR 99%):** При підвищенні рівня довіри до 99%, потенційний максимальний денний збиток різко зростає до 4.26%, що вказує на наявність екстремальних просадок в історії котирувань.
3. **Expected Shortfall (ES 95%):** Показник ES становить -3.71%. Це означає, що у найгірших 5% випадків (якщо збиток все ж таки проб'є поріг VaR 95%), *середні* денні втрати інвестора складуть 3.71%. ES дає більш реалістичну оцінку ризику під час кризових ситуацій на ринку, ніж класичний VaR.
